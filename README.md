# Whisper Studio 🎙️✨

**Whisper Studio** — автономное настольное Windows-приложение для локального распознавания речи (Speech-to-Text) и интеллектуального конспектирования лекций с помощью локальных нейросетей (LLM Summarizer).

Построено на базе двух передовых локальных AI-движков с аппаратным ускорением **NVIDIA GeForce RTX** (CUDA 12):
1. **`faster-whisper`** (CTranslate2) — сверхбыстрая транскрибация аудио- и видеозаписей любой длины.
2. **`llama-cpp-python`** (GGUF) — локальный запуск флагманских языковых моделей (**Qwen 2.5** и **DeepSeek-R1-Distill**) для создания структурированных академических конспектов без обращения к облакам.

---

## ✨ Ключевые возможности

### 🎙️ Модуль распознавания речи (Whisper)
- 🚀 **Zero-Config запуск в 1 клик (`run.bat`):** Скрипт сам находит совместимый Python (3.10–3.13), развёртывает `.venv`, устанавливает CUDA 12 библиотеки (`cublas`, `cudnn`, `cudart`, `llama-cpp-python` с CUDA-бэкендом) и запускает приложение.
- ⚡ **Аппаратное ускорение NVIDIA RTX:** Поддержка архитектур Ada Lovelace (RTX 40-серия, sm_89) и Blackwell (RTX 50-серия, sm_120). Скорость транскрибации — **10x–30x** быстрее реального времени.
- 📝 **Умная разбивка на абзацы (Smart Paragraphing):** Автоматическая группировка фраз в абзацы по паузам лектора (>1.8 сек) и пунктуации.
- 🧈 **Плавный 200+ FPS интерфейс:** Потокобезопасная асинхронная очередь (`queue.Queue`) и батчевая вставка текста исключают зависания окна даже на многочасовых записях.
- 💾 **Автосохранение:** По завершении распознавания файл `{название}_transcript.txt` автоматически сохраняется рядом с исходным медиа.
- 📤 **Экспорт в 4 формата:** Чистый структурированный `.TXT`, субтитры `.SRT` и `.VTT`, а также подробный `.JSON`.

### ✨ Модуль «AI-Конспектолог» (LLM Summarizer)
- 🔄 **Бесшовная передача в 1 клик:** Кнопка **«✨ Сгенерировать конспект лекции»** мгновенно передает распознанный текст во вкладку конспектирования без ручного копирования.
- 🧠 **Флагманские локальные модели GGUF:**
  - **Qwen 2.5 7B Instruct (Q4_K_M)** — превосходное понимание русского языка, глубокая систематизация академических тем (~4.7 GB).
  - **Qwen 2.5 3B Instruct (Q4_K_M)** — ультрабыстрая легковесная модель для ноутбуков (~2.2 GB).
  - **DeepSeek-R1-Distill-Qwen-7B (Q4_K_M)** — модель с цепочкой рассуждений (Reasoning) для сложных технико-математических дисциплин (~4.7 GB).
- 🛡️ **VRAM Arbiter (Защита от OOM на 8 GB GPU):** Интеллектуальный менеджер видеопамяти автоматически выгружает Whisper перед запуском LLM и наоборот, гарантируя стабильную работу на видеокартах класса **RTX 4060 Laptop (8 GB)** без сбоев Out of Memory.
- ⚡ **Rust-ускоритель скачивания (`hf_transfer`):** Поддержка бесплатного токена Hugging Face и Rust-библиотеки `hf_transfer` ускоряет загрузку весов моделей до **50–100+ МБ/с**.
- 📋 **Готовые академические шаблоны:**
  - *Академический конспект:* Определение темы, ключевые термины с дефинициями, иерархическая структура, формулы и итоговые выводы.
  - *Краткие тезисы (Executive Summary):* 5–7 главных мыслей и выжимка сути лекции за 2 минуты.
  - *Вопросы к экзамену:* Список экзаменационных вопросов и контрольных тем для самопроверки.
  - *Свой промпт:* Свободная инструкция для решения нестандартных аналитических задач.
- 📄 **Экспорт с Markdown и без него:**
  - Кнопки копирования: **«Копировать MD»** (для Obsidian, Notion, GitHub) и **«Копировать текст»** (чистый текст без спецсимволов `#`, `*`, `-`).
  - Кнопки сохранения: **`.MD`** и **`.TXT`**.

## 🖥️ Интерфейс приложения

Окно разделено на две основные вкладки в премиальном дизайне **Zinc / Monochrome**:
1. **`[ 🎙️ Аудио и Транскрибация ]`** — загрузка медиафайла, выбор модели Whisper, выбор языка и точности, распознавание в реальном времени с подсветкой поиска и экспортом.
2. **`[ ✨ AI-Конспект ]`** — выбор LLM-модели, выбор шаблона конспекта, настройка контекстного окна (до 32k токенов), потоковый вывод текста конспекта с замером скорости (токен/сек) и двойным экспортом (.md / .txt).

В шапке окна постоянно отображается статус видеокарты и **актуальный расход видеопамяти (VRAM)** в реальном времени, а также кнопка быстрого управления токеном **🔑 HF Token**.

## 🚀 Быстрый старт

### Требования
- **ОС:** Windows 10 / 11 (64-bit).
- **GPU (рекомендуется):** NVIDIA GeForce RTX 20xx / 30xx / 40xx / 50xx (от 6–8 GB VRAM).
- *(Опционально)* Python 3.10 – 3.13 (если не установлен, скрипт `run.bat` предложит автоустановку).

### Запуск
Просто дважды кликните по файлу:
```text
run.bat
```
Либо запустите его из PowerShell / CMD:
```powershell
.\run.bat
```

При первом запуске скрипт автоматически:
1. Создаст виртуальное окружение `.venv` и установит все зависимости, включая `llama-cpp-python` с поддержкой CUDA 12.
2. Проверит наличие CUDA DLLs и настроит запуск на GPU.
3. Откроет приложение Whisper Studio.

## 📁 Структура проекта

```text
ai-lectures/
│
├── core/                        # Ядро приложения и AI-бэкенды
│   ├── audio_utils.py           # Метаданные, умные абзацы, экспорт TXT/SRT/VTT/JSON
│   ├── cuda_utils.py            # Детекция GPU, регистрация DLL CUDA 12 (cuBLAS, cuDNN, cuDART)
│   ├── hf_downloader.py         # Реестр LLM, ускоренная загрузка (hf_transfer, HF Token)
│   ├── llm_engine.py            # Движок llama-cpp-python, offload в GPU, FlashAttention, стриминг
│   ├── model_manager.py         # Загрузка и локальный кэш моделей Whisper
│   ├── summarizer.py            # Академические шаблоны, Map-Reduce чанкинг, очистка Markdown
│   ├── transcriber.py           # Потоковый инференс faster-whisper, Silero VAD
│   └── vram_manager.py          # VRAM Arbiter: взаимная выгрузка Whisper/LLM, защита от OOM
│
├── ui/                          # Пользовательский интерфейс (CustomTkinter)
│   ├── components.py            # GPUBadge, интерактивный DropZone, CollapsibleSection, Toast
│   ├── hf_token_dialog.py       # Модальное окно настройки токена Hugging Face Hub
│   ├── main_window.py           # Главное окно, вкладки навигации, мониторинг VRAM
│   ├── onboarding.py            # Диалог первого запуска и быстрой загрузки модели
│   ├── summary_view.py          # Вкладка конспектирования, пресеты, стриминг токенов, экспорт
│   └── theme.py                 # Палитра Zinc / Monochrome, шрифты и геометрия
│
├── models/                      # Локальный каталог кэша AI-моделей
│   └── llm/                     # Локальный каталог кэша GGUF-моделей
├── app.py                       # Главная точка входа Python
├── run.bat                      # Автономный загрузчик Zero-Config для Windows
├── requirements.txt             # Список протестированных зависимостей
└── README.md                    # Документация проекта
```

## 🛠️ Стек технологий

- **STT-движок:** [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (CTranslate2)
- **LLM-движок:** [llama-cpp-python](https://github.com/abetlen/llama-cpp-python) с CUDA 12 бэкендом
- **Модели:** OpenAI Whisper, Qwen 2.5 (Alibaba Cloud), DeepSeek-R1 Distill
- **Ускорение загрузок:** `hf-transfer` (Rust-бэкенд для Hugging Face Hub)
- **Нейросетевой VAD:** Silero Voice Activity Detector
- **Аппаратное ускорение:** NVIDIA CUDA 12 (`nvidia-cublas-cu12`, `nvidia-cudnn-cu12`, `nvidia-cuda-runtime-cu12`)
- **Графический интерфейс:** [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)
- **Drag & Drop:** `windnd` (Windows Native Drop Target API)
- **Медиа:** `PyAV` (FFmpeg C-bindings), `imageio-ffmpeg`
