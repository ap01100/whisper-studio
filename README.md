# Whisper Studio 🎙️

**Whisper Studio** — автономное настольное Windows-приложение для локального распознавания речи (Speech-to-Text) и транскрибирования аудио- и видеозаписей любой продолжительности.

Построено на базе сверхбыстрого движка **`faster-whisper`** (CTranslate2) с полноценным аппаратным ускорением на видеокартах **NVIDIA GeForce RTX** (CUDA 12).

---

## ✨ Ключевые возможности

- 🚀 **Zero-Config запуск в 1 клик (`run.bat`):** Скрипт сам находит совместимый Python (3.10–3.13), развёртывает виртуальное окружение `.venv`, подтягивает CUDA-библиотеки и запускает приложение без ручной настройки.
- ⚡ **Аппаратное ускорение NVIDIA RTX:** Нативная поддержка архитектур Ada Lovelace (RTX 40-серия, sm_89) и Blackwell (RTX 50-серия, sm_120) через CUDA 12 и библиотеки `cublas`, `cudnn`. Скорость инференса достигает **10x–30x** относительно реального времени.
- 🔒 **100% приватность и офлайн:** Никаких облачных API и отправки данных. Все веса моделей и вычисления хранятся и исполняются исключительно локально на вашем компьютере.
- 📝 **Умная разбивка на абзацы (Smart Paragraphing):** Автоматическая группировка фраз в структурированные абзацы по паузам лектора (>1.8 сек) и пунктуации. Никаких бесконечных сплошных строк.
- 🧈 **Плавный 200+ FPS интерфейс:** Потокобезопасная асинхронная очередь (`queue.Queue`) и батчевая вставка текста исключают подвисания окна даже на многочасовых лекциях.
- 💾 **Автоматическое сохранение (Auto-Save):** По завершении работы файл `{название}_transcript.txt` автоматически сохраняется в папку с исходным файлом, а кнопка **«📂 Открыть папку»** мгновенно показывает результат в Проводнике.
- 📁 **Удобный Drag & Drop:** Перетаскивание аудио- и видеофайлов прямо из Проводника Windows (на базе `windnd`).
- 🎯 **Широкая поддержка форматов:** MP3, WAV, M4A, FLAC, OGG, AAC, WMA, MP4, MKV, MOV, AVI, WebM.
- 📤 **Экспорт в популярные форматы:**
  - **.TXT** — чистый структурированный текст лекции или с таймкодами;
  - **.SRT** — субтитры SubRip для видеоплееров и YouTube;
  - **.VTT** — субтитры WebVTT для веб-интерфейсов;
  - **.JSON** — полная метаинформация с вероятностями, длительностью и таймкодами каждого слова.
- 🎨 **Премиальный дизайн (Zinc / Monochrome):** Минималистичная темная тема с контрастными белыми акцентными кнопками, плавной индикацией прогресса, живым поиском и бейджем состояния GPU.

## 🖥️ Скриншоты и интерфейс

Интерфейс разделён на две зоны:
1. **Панель управления (слева):**
   - Интерактивная зона сброса и выбора файла (DropZone).
   - Выбор модели из каталога (от `tiny` до `large-v3-turbo`).
   - Выбор языка аудио (или автоопределение).
   - Аккордеон расширенных настроек: выбор точности (`float16`, `int8_float16`, `int8`), VAD-фильтр шума и пауз Silero, Beam Size (1–5), тумблеры автосохранения и живого предпросмотра.
2. **Панель результата (справа):**
   - Индикатор прогресса и текущей скорости инференса (в `x` от реалтайма).
   - Переключатель режимов: **«Чистый текст»** / **«С таймкодами»**.
   - Живой поиск по распознанному тексту с подсветкой.
   - Кнопка быстрого копирования в буфер обмена с всплывающим тостом.
   - Кнопки экспорта и быстрого открытия папки с файлом.

## 🚀 Быстрый старт

### Требования
- **ОС:** Windows 10 / 11 (64-bit).
- **GPU (рекомендуется):** NVIDIA GeForce GTX 10xx / RTX 20xx / 30xx / 40xx / 50xx с актуальным видеодрайвером (драйвер 527.41+).
- *(Опционально)* Python 3.10 – 3.13 (если не установлен, скрипт `run.bat` предложит автоустановку).

### Запуск
Просто дважды кликните по файлу:
```text
run.bat
```
Либо запустите его из терминала:
```powershell
.\run.bat
```

При первом запуске:
1. Создастся виртуальное окружение `.venv` и установятся все зависимости.
2. Откроется окно Whisper Studio с предложением скачать стартовую модель (например, оптимальную `base` или флагманскую `large-v3-turbo`).
3. Перетащите ваш файл в окно и нажмите **«Начать транскрибирование»**.

## 🧠 Поддерживаемые модели Whisper

| Модель | Размер | Требуемая VRAM | Скорость | Рекомендуемое назначение |
|---|---|---|---|---|
| **`large-v3-turbo`** ⭐ | ~1.6 GB | от 4–6 GB | Сверхбыстрая | **Лучший баланс качества и скорости на современных RTX** |
| **`large-v3`** | ~3.1 GB | от 6–8 GB | Средняя | Максимальная точность для сложной терминологии |
| **`medium`** | ~1.5 GB | от 4 GB | Быстрая | Отличное качество для большинства задач |
| **`small`** | ~480 MB | от 2 GB | Очень быстрая | Легковесная модель для средних ПК |
| **`base`** | ~145 MB | от 1 GB | Мгновенная | Быстрые черновые расшифровки |
| **`tiny`** | ~75 MB | < 1 GB | Максимальная | Минимальное потребление ресурсов |

*Все модели скачиваются в папку `./models` один раз и затем работают полностью автономно.*

## 📁 Структура проекта

```text
ai-lectures/
│
├── core/                        # Ядро распознавания и утилиты
│   ├── audio_utils.py           # Аудио/видео метаданные, парсер абзацев, экспорт .txt/.srt/.vtt/.json
│   ├── cuda_utils.py            # Детекция GPU, регистрация DLL cuBLAS/cuDNN CUDA 12
│   ├── model_manager.py         # Загрузка и локальный кэш моделей Hugging Face
│   └── transcriber.py           # Потоковый инференс faster-whisper, VAD Silero, отмена задачи
│
├── ui/                          # Пользовательский интерфейс (CustomTkinter)
│   ├── components.py            # GPUBadge, интерактивный DropZone, CollapsibleSection, Toast
│   ├── main_window.py           # Главное окно, тулбары, текстовый редактор, очередь 200 FPS
│   ├── onboarding.py            # Диалог первого запуска и скачивания модели
│   └── theme.py                 # Палитра Zinc / Monochrome, типографика и геометрия
│
├── models/                      # Локальный каталог кэша моделей AI
├── app.py                       # Главная точка входа Python
├── run.bat                      # Автономный загрузчик Zero-Config для Windows
├── requirements.txt             # Список протестированных зависимостей
└── README.md                    # Документация проекта
```

## 🛠️ Стек технологий

- **Движок распознавания:** [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (CTranslate2)
- **Нейросетевой VAD:** Silero Voice Activity Detector
- **Аппаратное ускорение:** NVIDIA CUDA 12 (пакеты `nvidia-cublas-cu12`, `nvidia-cudnn-cu12`)
- **Графический интерфейс:** [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)
- **Drag & Drop:** `windnd` (Windows Native Drop Target API)
- **Работа с медиа:** `PyAV` (FFmpeg C-bindings), `imageio-ffmpeg`
